Trajectory parameters: seeded stochastic goals, correlated small heading changes, and a 0.15 m modeled wall-clearance guard. Each 0.16 s simulation step travels 0.107 m (nominal 0.669 m/s). A seed reproduces the same motion; New random path changes it. This is not neural motor control. Scientific interpretation. The arena geometry is used to ray-cast a synthetic LiDAR scan; its endpoints are projected into the world frame using an exact simulated pose. A specified north/east/south/west wall (or circular arc) is selected before the experiment. The highlighted map is an occupancy-normalized readout of generated spikes, not a learned synaptic weight map. A true biological border-cell claim requires additional neural recordings and controls; a robotics learning claim requires estimated pose, noisy mapping, and an explicit learning rule.
