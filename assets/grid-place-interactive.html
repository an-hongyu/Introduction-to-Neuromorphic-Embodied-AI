Spatial cell models · browser experiment

Grid cells → place-like fields

Change spacing, orientation, phase, gain, and offset; then inspect how multiple periodic inputs combine. This explicit feedforward teaching model follows Liu and colleagues' grid/interference and threshold-sum framework. It does not train synapses or simulate spikes.

1 · Select an input grid

Each grid has its own parameters and weight. The blue border identifies the selected grid. Angles describe a nearest-neighbor lattice axis; 0° and 60° give the same ideal lattice.

All six input maps use the same fixed 0–80 Hz color scale. Inputs outside the chosen population are shown but excluded from the readout. Click a map to move the probe; the x/y sliders below provide a keyboard alternative. Coordinates cover −1 to +1 m in both axes, with +y upward.

2 · Combine the inputs

gⱼ(r) = 20 Hz · max[0, κⱼ Σₘ₌₀² cos(kⱼ eⱼₘ · (r − pⱼ)) + ζⱼ],   kⱼ = 4π/(√3 λⱼ)
hⱼ = gⱼ/gⱼ,max;   S = Σ wⱼ hⱼ / Σ wⱼ;   rₚ = 25 Hz · max[0, (S − τ)/(1 − τ)]

Wave-vector axes eⱼₘ are θⱼ + 30° + m·60°. The extra 30° makes θ name a lattice axis. gⱼ,max = 20 Hz · max(0,3κⱼ + ζⱼ); hⱼ = 0 if this maximum is zero. Zero total weight gives S = 0. The normalization intentionally removes pure gain changes when ζ = 0; the raw grid-rate panels still show them.

3 · Inspect the probe inputs

Bars show wⱼhⱼ / Σwⱼ; labels also report the raw grid rate. The contribution sum equals the pooled drive S. Probe values are evaluated continuously; maps and patch counts use a 121×121 grid.

Read the result

Start with One grid only: repeated grid peaks remain repeated after thresholding. Compare Identical grids, then Diverse grids. Diversity can suppress extra peaks in this arena, but a single localized output is not guaranteed. Lower τ to merge regions; raise it to narrow or remove them. Shift one input's phase to disrupt a shared peak.

κ and ζ here are dimensionless gain and additive offset, with a declared 20 Hz scale. ζ names the additive b term of the cosine teaching model; it is not the same operation as ζ inside the 2025 paper's arctangent expression. Phase is a 2-D translation in metres; the equivalent wave phases are kⱼeⱼₘ·pⱼ radians. No per-map autoscaling hides changes in raw rates.

Peak phases are deliberately aligned in the presets. These are designed inputs and fixed weights, not learned place fields, path integration, animal recordings, or proof that the brain uses a unique one-way conversion. No Gaussian place field is inserted into this readout.
