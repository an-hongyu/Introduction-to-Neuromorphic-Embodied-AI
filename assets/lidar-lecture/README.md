# LiDAR lecture illustrations and media

Extracted from Hongyu An's supplied 56-slide Introduction to LiDAR lecture at the author's request. These are original source images and two original GIF animations, not AI redraws. The full slide deck is not redistributed. The manifest records slide order, source hashes, crops, panel arrangements, final hashes, dimensions, and animation frame counts. Original credits and labels are retained; any precise attribution absent in the lecture is not invented. Third-party material retains its original rights and is not covered by a new license from this repository.

The three videos are external YouTube references in the PowerPoint, not embedded video files. Their original IDs, poster images, and metadata titles are preserved. The player loads YouTube only on click and always provides a direct link. Availability and regional embedding restrictions depend on the host.

- `lidar-applications.png`: slide(s) [3]; LiDAR on vehicles, consumer devices, and airborne platforms. Slide credit: Uber, Apple, Xiaomi, DJI.
- `time-of-flight.png`: slide(s) [6]; From a transmitted pulse to a delayed return. 
- `lidar-components.png`: slide(s) [15, 16, 17]; Transmitter, receiver, timing, and processing paths. 
- `mechanical-and-multibeam.png`: slide(s) [15, 18]; Mechanical scanning and multiple elevation channels. The multichannel illustration identifies a Hesai device.
- `planar-scan-animation.gif`: slide(s) [8, 18]; A planar scanner builds up angular range samples. Original source attribution is not fully specified in the lecture.
- `silicon-photonics-lidar.png`: slide(s) [20, 21]; Silicon-photonic switching and beam steering. Xiaosheng Zhang et al., Nature 603, 253-258 (2022), doi:10.1038/s41586-022-04415-8; CC BY 4.0 for the cited paper material.
- `phased-array-animation.gif`: slide(s) [21]; Phase relationships change the illustrated beam direction. Original source attribution is not fully specified in the lecture.
- `aerial-data-collection.png`: slide(s) [23]; Airborne scanning combines range, platform position, and attitude. From the supplied lecture PDF.
- `multiple-return-waveforms.png`: slide(s) [26]; A pulse can produce several return peaks. Lecture source: NEON LiDAR basics tutorial.
- `tree-return-classes.png`: slide(s) [27]; Tree points colored by return order. 
- `bathymetric-lidar.png`: slide(s) [28]; Water-surface and bottom returns in bathymetric surveying. 
- `field-of-view.png`: slide(s) [30, 32]; Field of view, angular spacing, and range are different quantities. 
- `angular-resolution.png`: slide(s) [31]; Angular sampling changes the detail captured on a distant object. Slide credit: LIDAR for Autonomous System Design: Object Classification or Object Detection?
- `blind-spots.png`: slide(s) [33]; Coverage and mounting geometry leave blind spots. 
- `point-cloud-data.png`: slide(s) [35]; Planar mapping and a three-dimensional road point cloud. 
- `camera-and-lidar.png`: slide(s) [36, 37]; Image appearance and metric range geometry. Lecture image credits include KITTI, Apple, Cartographer, and NASA.
- `reflection-effects.png`: slide(s) [39]; Glass can create transmitted, reflected, and misleading returns. Slide source label: Mapping with Reflection-Detection and Utilization of Reflection in 3D Lidar Scans.
- `weather-returns.png`: slide(s) [40]; Atmospheric particles can compete with the target return. Slide credit: Velodyne.
- `scan-motion-distortion.png`: slide(s) [43]; The scene changes while a sequential scan is acquired. From the supplied lecture PDF.
- `wads-winter-point-cloud.png`: slide(s) [45]; A winter driving point cloud from the lecture. Akhil Kurup and Jeremy Bos, WADS, Michigan Technological University, 2021.
- `cadc-driving-example.png`: slide(s) [48]; Adverse-weather driving and the corresponding LiDAR view. Canadian Adverse Driving Conditions Dataset; source link retained from the lecture.
- `waymo-lidar-labels.png`: slide(s) [51]; Point clouds with object annotations. Waymo Open Dataset; screenshot in supplied lecture, not a current leaderboard.
- `sydney-urban-objects.png`: slide(s) [53]; Different object shapes represented as point sets. Sydney Urban Objects Dataset; source link retained from the lecture.
- `lidar-detection-example.png`: slide(s) [54]; Object-detection output shown on a point cloud. MathWorks: Lidar Object Detection Using Complex-YOLO v4.
