Try: start with 100 pA, then 200 pA. Double capacitance while keeping current and leak fixed. Increase the refractory duration: the first spike stays at the same time, but subsequent spikes slow down.

Model: C dV/dt = −g(V − EL) + I; EL = −65 mV. The same exact passive update and endpoint threshold/reset rule as the Python notebook are used, with Δt = 0.1 ms. Steady rate is 1000 / mean interspike interval, shown only after two spikes. A 500 ms spike count divided by 0.5 s is a different finite-window estimate. Spike markers do not model action-potential waveforms. These are teaching parameters, not a fit to a biological neuron.
